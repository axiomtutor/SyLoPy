## Proof that 
### if a, b, c, are integers such that: a|b and a|c
### then a|Plus(b, c)

1. Let a, b, c be integers such that: a|b and a|c. (Premise)
2. (a|b and a|c) if and only if (exists m, n such that: b = Times(a, m) and c = Times(a, n)). (Definition)
3. Let m, n be objects. (Declare)
4. Exists m, n such that: b = Times(a, m) and c = Times(a, n). (Existential Elimination from 1)
5. Plus(b, c) = Plus(Times(a, m), Times(a, n)). (Substitution from 4)
6. Plus(b, c) = Times(a, Plus(m, n)). (Algebra from 5)
7. a|Plus(b, c). (Existential Introduction from 6)
