


(* 
Note on formatting: Anything inside of paren-stars is a comment, and not read by the proof checker.
A comment can occur on any line, anywhere in the document.
Proofs are formatted by 
- A hash and a number indicating a new proof.
- A double-hash and a line indicating that it is a "proof that". For testing purposes, this can also indicate "invalid proof", but the typical user will not need this.
- A triple-hash and a line indicating the premises of the theorem.
- A triple-hash and a line indicating the conclusion of the thoerem.
- An empty line.
- The proof, indexed starting at 1, with the first line stating "Let" and then writing out the premises.  This line declares the object types, and any assumed statements about them.
- An empty line.
Additional white space beyond this is ignored by the checker.
*)

## Proof that 
### if A, B, C are closed formulas such that: A -> B. B -> C. C -> A. 
### then A -> C.
(* Proof with unnecessary steps. *)

1. Let A, B, C be closed formulas such that: A -> B. B -> C. C -> A. (Premise)
2. A -> C. (Hypothetical Syllogism from 1)
3. A <-> C. (Biconditional Introduction from 1,2)
4. C -> A. (Biconditional Elimination from 3)
5. A -> C. (Biconditional Elimination from 3)

# 2
## Proof that 
### if A, B are closed formulas such that: not (if A then B). 
### then A and not B.

1. Let A, B be closed formulas such that: not (if A then B). (Premise)
(* Comments can even come in the middle of a proof. *)
2. A and not B. (Proof by Contradiction from subproof below)
begin subproof
 2.1. not (A and not B). (Assumption for Contradiction)
 2.2. not A or not (not B). (De Morgans from 2.1)
 2.3. not A or B. (Double Negation from 2.2)
 2.4. if A then B. (Conditional Equivalence from 2.3)
 2.5. (if A then B) and not (if A then B). (Conjunction Introduction from 2.4, 1)
end subproof

## Proof that 
### if A, B are closed formulas.
### then A -> (B -> A).
(* Doubly nested subproofs. *)

1. Let A, B be closed formulas.
2. A -> (B -> A). (Conditional Introduction from subproof below)
begin subproof
 1.1. A. (Assumption for conditional introduction)
 1.2. B -> A. (Conditional Introduction from subproof below)
 begin subproof
  1.2.1. B. (Assumption for conditional introduction)
  1.2.2. A. (Reiteration from 1.1)
 end subproof
end subproof

### then exists z, not Q(z).

5. not (A or B). (Modus Tollens from 2, 4)

 9.1. P(c). (Assumption for Existential Elimination)
 9.2. P(c) -> not Q(c). (Universal Instantiation from 2)
 9.3. not Q(c). (Modus Ponens from 9.1, 9.2)
 9.4. exists z, not Q(z). (Existential Introduction from 9.3)
end subproof
