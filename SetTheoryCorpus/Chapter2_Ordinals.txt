# Definition 1. Partial ordering.
## Let P be a set, < a relation on P.
### The relation < is a **partial ordering on P** if 
### the relation < is anti-reflexive and transitive.
### The pair (P, <) is called a **partially ordered set** or **poset** if 
### the relation < is a partial ordering on P.

# Definition 2. Linear ordering.
## Let (P, <) be a poset.
### The relation < is a **linear ordering on P** if 
### the relation < is connected.

# Definition 3. Less-than-or-equal-to.
## Let (P, <) be a poset.  
### The symbol <= denotes the relation defined by
### for all x, y in P, x <= y if and only if (x < y or x = y)

# Definition 4. Bound, extrema, sup, inf.
## Let (P, <) be a poset, X is a nonempty subset of P, and (a in P).
### If (a in X) and (for all x in X, a (not <) x) then a is a **maximal element of X**.  This is denoted **max(X)**.
### If (a in X) and (for all x in X, x (not <) a) then a is a **minimal element of X**.  This is denoted **min(X)**.
### If (a in X) and (for all x in X, x <= a) then a is the **greatest element of X**.  
### If (a in X) and (for all x in X, a <= x) then a is the **least element of X**.
### If (for all x in X, x <= a) then a is an **upper bound of X**.
### If (for all x in X, a <= x) then a is a **lower bound of X**.  
### If U is the set of upper bounds of X, and a is the least element of U, then a is the **supremum of X**.  This is denoted **sup(X)**.
### If L is the set of lower bounds of X, and a is the greatest element of L, then a is the **infimum of X**.  This is denoteed **inf(X)**.
