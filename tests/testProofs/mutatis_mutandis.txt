(*
Mutatis mutandis, stages 1 and 2: names replaced by names, and by terms.

`P'. (Mutatis mutandis, A to B)` repeats the argument of line B for the names
that make B say P'; a single citation `B` repeats the argument of line B alone.
A name may be replaced by another name or by a term with no variable in it
(cases 31 to 40). The validator expands the line into the repeated argument and
checks that like any other, so each refusal below is an ordinary refusal at the
Mutatis mutandis line. Every invalid case has a valid case that differs from it
only in the point it names.
*)

### then (P(a) -> R(a)) and (P(b) -> R(b)).

2. Let P, Q and R be predicates. (Declare)
3. P(a) -> Q(a). (Premise)
4. Q(a) -> R(a). (Premise)
5. P(b) -> Q(b). (Premise)
6. Q(b) -> R(b). (Premise)
7. P(a) -> R(a). (Conditional Introduction from subproof below)
begin subproof
 7.1. P(a). (Assumption for Conditional Introduction)
 7.2. Q(a). (Modus Ponens from 3, 7.1)
 7.3. R(a). (Modus Ponens from 4, 7.2)
end subproof
8. P(b) -> R(b). (Mutatis mutandis, 3 to 7)
9. (P(a) -> R(a)) and (P(b) -> R(b)). (Conjunction Introduction from 7, 8)
