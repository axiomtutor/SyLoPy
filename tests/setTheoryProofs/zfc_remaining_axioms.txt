# Axiom 1: Axiom of extensionality.
### If X and Y are sets, 
### then X = Y iff (for all a in X we have a in Y, and 
### for all a in Y we have a in X)

# Axiom 2: Axiom of pairing.
### If a and b are sets, 
### then there is a set {a, b} that contains exactly a and b.

# Axiom 3: Axiom schema of separation.
### If P is a property with parameter p, 
### then for any X and p there exists a set Y = {u in X: P(u,p)}.

# Axiom 4: Axiom of union.
### If X is a set then there is a set Y = (union X) 
### = {u in U: U in X}

# Axiom 5: Axiom of power set.  
### If X is a set 
### then there is a set Y = P(X) 
### = {y: y subset X}

# Axiom 6: Axiom of infinity.  
### There is an infinite set.

# Axiom 7: Axiom schema of replacement.
### If the class F is a function, and X a set,
### then there exists a set Y = F(X) 
### = {F(x): x in X}

# Axiom 8: Axiom of regularity.
### Every nonempty set has an in-minimal element.

# Axiom 9: Axiom of choice.
### If (Fam) is a family of nonempty sets, 
### then there is a choice function of those sets.

# 1: Unique pairing.
## Proof that 
### If a and b are sets, 
### then there exists a unique set {a, b} that contains exactly a and b.

1. a and b are sets. (Declaration)
2. Exists Y, forall u, (In(u, Y) iff (u = a or u = b)). (Axiom of pairing)
3. If (forall z, (In(z, X) iff (z = a or z = b))) then X = Y. (Conditional Introduction from subproof below)
 3.1. Forall z, (In(z, X) iff (z = a or z = b)).  (Assumption for Conditional Introduction)
 3.2. X subseteq Y. (Subset proof below)
  3.2.1. Let x in X.  (Assumption for subset proof)
  3.2.2. x = a or x = b.  (Set property, 3, 3.2.1)
  3.2.3. x = a. (WLOG)
  3.2.4. In(x, Y). (Set property, 2, 3.2.3)
 3.3. Y subseteq X. (Mutatis mutandis, 3.1 to 3.2)
 3.4. X = Y. (Set equality, 3.2, 3.3)
4. Exists Y, (forall u, (In(u, Y) iff (u = a or u = b))) and (forall X, (forall z, (In(z, X) iff (z = a or z = b))) -> X = Y). (Uniqueness, 2, 3)
