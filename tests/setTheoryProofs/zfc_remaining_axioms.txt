# Worked examples for the five ZFC axioms/schemas added alongside
# empty_set_subset.txt's extensionality-and-subset theorem: Pairing, Union,
# Power Set and Infinity (plain axioms, cited "(Axiom)" and written out
# verbatim, the same way NumberTheory's Times-associativity/distributivity
# axioms are already cited), plus Separation and Replacement (schemas,
# cited "(Separation)"/"(Replacement)" with no premises -- see
# SeparationSchemaRule/ReplacementSchemaRule in SetTheory.py for why these
# two are rules rather than formulas).
#
# Kept in their own file rather than appended to empty_set_subset.txt:
# pytest_tests/test_theorem_promotion_and_set_theory.py parses that file's
# entire contents directly as a single proof (not through the #N
# multi-proof container), so it has to stay a single proof.


# 1: Pairing gives a set containing two given sets
## Proof that
### then exists Y, (In(p, Y) and In(q, Y)).

1. Let p, q be any set. (Declaration)
2. forall a, forall b, exists Y, forall u, (In(u, Y) <-> (u = a or u = b)). (Axiom)
3. forall b, exists Y, forall u, (In(u, Y) <-> (u = p or u = b)). (Universal Instantiation from 2)
4. exists Y, forall u, (In(u, Y) <-> (u = p or u = q)). (Universal Instantiation from 3)
5. Let R be any set. (Declaration)
6. exists Y, (In(p, Y) and In(q, Y)). (Existential Elimination from 4, subproof below)
begin subproof
 6.1. forall u, (In(u, R) <-> (u = p or u = q)). (Assumption for Existential Elimination)
 6.2. In(p, R) <-> (p = p or p = q). (Universal Instantiation from 6.1)
 6.3. (p = p or p = q) -> In(p, R). (Biconditional Elimination from 6.2)
 6.4. p = p. (Reflexivity)
 6.5. p = p or p = q. (Disjunction Introduction from 6.4)
 6.6. In(p, R). (Modus Ponens from 6.3, 6.5)
 6.7. In(q, R) <-> (q = p or q = q). (Universal Instantiation from 6.1)
 6.8. (q = p or q = q) -> In(q, R). (Biconditional Elimination from 6.7)
 6.9. q = q. (Reflexivity)
 6.10. q = p or q = q. (Disjunction Introduction from 6.9)
 6.11. In(q, R). (Modus Ponens from 6.8, 6.10)
 6.12. In(p, R) and In(q, R). (Conjunction Introduction from 6.6, 6.11)
 6.13. exists Y, (In(p, Y) and In(q, Y)). (Existential Introduction from 6.12)
end subproof


# 2: Union gives a set witnessing membership two levels down
## Proof that
### then exists Y, In(p, Y).

1. Let p, q, W be any set. (Declaration)
2. p is in q. (Premise)
3. q is in W. (Premise)
4. forall X, exists Y, forall u, (In(u, Y) <-> exists v, (In(v, X) and In(u, v))). (Axiom)
5. exists Y, forall u, (In(u, Y) <-> exists v, (In(v, W) and In(u, v))). (Universal Instantiation from 4)
6. Let U be any set. (Declaration)
7. exists Y, In(p, Y). (Existential Elimination from 5, subproof below)
begin subproof
 7.1. forall u, (In(u, U) <-> exists v, (In(v, W) and In(u, v))). (Assumption for Existential Elimination)
 7.2. In(p, U) <-> exists v, (In(v, W) and In(p, v)). (Universal Instantiation from 7.1)
 7.3. (exists v, (In(v, W) and In(p, v))) -> In(p, U). (Biconditional Elimination from 7.2)
 7.4. In(q, W) and In(p, q). (Conjunction Introduction from 3, 2)
 7.5. exists v, (In(v, W) and In(p, v)). (Existential Introduction from 7.4)
 7.6. In(p, U). (Modus Ponens from 7.3, 7.5)
 7.7. exists Y, In(p, Y). (Existential Introduction from 7.6)
end subproof


# 3: Power Set contains every subset
## Proof that
### then exists Y, In(p, Y).

1. Let p, q be any set. (Declaration)
2. forall v, (In(v, p) -> In(v, q)). (Premise)
3. forall X, exists Y, forall u, (In(u, Y) <-> forall v, (In(v, u) -> In(v, X))). (Axiom)
4. exists Y, forall u, (In(u, Y) <-> forall v, (In(v, u) -> In(v, q))). (Universal Instantiation from 3)
5. Let U be any set. (Declaration)
6. exists Y, In(p, Y). (Existential Elimination from 4, subproof below)
begin subproof
 6.1. forall u, (In(u, U) <-> forall v, (In(v, u) -> In(v, q))). (Assumption for Existential Elimination)
 6.2. In(p, U) <-> forall v, (In(v, p) -> In(v, q)). (Universal Instantiation from 6.1)
 6.3. (forall v, (In(v, p) -> In(v, q))) -> In(p, U). (Biconditional Elimination from 6.2)
 6.4. In(p, U). (Modus Ponens from 6.3, 2)
 6.5. exists Y, In(p, Y). (Existential Introduction from 6.4)
end subproof


# 4: Infinity gives a set containing the empty set
## Proof that
### then exists X, In(EmptySet, X).

1. exists X, (In(EmptySet, X) and forall y, (In(y, X) -> exists S, ((forall u, (In(u, S) <-> (In(u, y) or u = y))) and In(S, X)))). (Axiom)
2. Let U be any set. (Declaration)
3. exists X, In(EmptySet, X). (Existential Elimination from 1, subproof below)
begin subproof
 3.1. In(EmptySet, U) and forall y, (In(y, U) -> exists S, ((forall u, (In(u, S) <-> (In(u, y) or u = y))) and In(S, U))). (Assumption for Existential Elimination)
 3.2. In(EmptySet, U). (Conjunction Elimination from 3.1)
 3.3. exists X, In(EmptySet, X). (Existential Introduction from 3.2)
end subproof


# 5: Separation carves a subset out by an arbitrary property
## Proof that
### then exists Y, forall u, (In(u, Y) <-> (In(u, X) and In(u, W))).

1. Let X, W be any set. (Declaration)
2. exists Y, forall u, (In(u, Y) <-> (In(u, X) and In(u, W))). (Separation)


# 6: Replacement carries a set across an arbitrary functional relation
## Proof that
### then (forall x, (In(x, A) -> exists y, ((y = x) and (forall z, (z = x -> z = y))))) -> (exists C, forall y, (In(y, C) <-> exists x, (In(x, A) and y = x))).

1. Let A be any set. (Declaration)
2. (forall x, (In(x, A) -> exists y, ((y = x) and (forall z, (z = x -> z = y))))) -> (exists C, forall y, (In(y, C) <-> exists x, (In(x, A) and y = x))). (Replacement)
