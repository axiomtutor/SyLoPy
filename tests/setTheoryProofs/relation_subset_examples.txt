(*
Examples showing how a relation declaration supplies carrier membership.
These proofs derive membership from R(a,b) rather than declaring a and b in X
only as unused premises.
*)

# 1: Reflexivity uses membership supplied by a relation fact
## Proof that
### if R is reflexive on X and R(a, b), then R(a, a),
### then R(a, a).

1. Let X be any set, R be a reflexive relation on X, a, b be objects, R(a,b). (Declaration)
2. forall y, (R(a,y) -> (In(a,X) and In(y,X))). (Universal Instantiation from 1)
3. In(a,X) and In(b,X). (Universal Modus Ponens from 2, 1)
4. In(a,X). (Conjunction Elimination from 3)
5. R(a,a). (Relation Reflexivity from 4)

# 2: Symmetry uses membership supplied by the reverse pair derivation
## Proof that
### if R is symmetric on X and R(a, b), then R(b, a),
### then R(b, a).

1. Let X be any set, R be a symmetric relation on X, a, b be objects, R(a,b). (Declaration)
2. forall y, (R(a,y) -> (In(a,X) and In(y,X))). (Universal Instantiation from 1)
3. In(a,X) and In(b,X). (Universal Modus Ponens from 2, 1)
4. R(b,a). (Relation Symmetry from 1)

# 3: Transitivity supplies membership for the derived pair
## Proof that
### if R is transitive on X, R(a, b), and R(b, c), then R(a, c),
### then R(a, c).

1. Let X be any set, R be a transitive relation on X, a, b, c be objects, R(a,b) and R(b,c). (Declaration)
2. R(a,c). (Relation Transitivity from 1, 1)

# 4: A partial order makes reflexive and antisymmetric conclusions
## Proof that
### if R is a partial order on X and R(a, b), then R(a, a),
### then R(a, a) and a = a.

1. Let X be any set, R be a partial order on X, a, b be objects, R(a,b). (Declaration)
2. forall y, (R(a,y) -> (In(a,X) and In(y,X))). (Universal Instantiation from 1)
3. In(a,X) and In(b,X). (Universal Modus Ponens from 2, 1)
4. In(a,X). (Conjunction Elimination from 3)
5. R(a,a). (Relation Reflexivity from 4)
6. a = a. (Reflexivity)
7. R(a,a) and a = a. (Conjunction Introduction from 5, 6)

# 5: A strict partial order derives irreflexivity after membership is supplied
## Proof that
### if R is a strict partial order on X and R(a, b), then not R(a, a),
### then not R(a, a).

1. Let X be any set, R be a strict partial order on X, a, b be objects, R(a,b). (Declaration)
2. forall y, (R(a,y) -> (In(a,X) and In(y,X))). (Universal Instantiation from 1)
3. In(a,X) and In(b,X). (Universal Modus Ponens from 2, 1)
4. In(a,X). (Conjunction Elimination from 3)
5. not R(a,a). (Relation Irreflexivity from 4)
