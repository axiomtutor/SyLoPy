# Basic theorems of axiomatic set theory. This file is meant to grow into
# a large corpus: each numbered proof below stands alone (its own
# declarations, no cross-references to the others), building up the
# standard early results from empty_set_subset.txt's axioms and
# SetTheory.py's rules the way a first chapter of a set theory textbook
# would. More theorems get added here over time -- this is a first
# installment of three, not the whole chapter.


# 1: Subset is reflexive
## Proof that
### then X is a subset of X.

1. Let X be any set. (Declaration)
2. X is a subset of X. (Subset proof below)
 2.1. Let a in X. (Assumption for subset proof)
 2.2. a is in X. (Reiteration from 2.1)


# 2: Subset is transitive
## Proof that
### If X is a subset of Y and Y is a subset of Z
### then X is a subset of Z.

1. Let X, Y, Z be any set. (Declaration)
2. X is a subset of Y. (Premise)
3. Y is a subset of Z. (Premise)
4. X is a subset of Z. (Subset proof below)
 4.1. Let a in X. (Assumption for subset proof)
 4.2. In(a,X) -> In(a,Y). (Universal Instantiation from 2)
 4.3. In(a,Y). (Modus Ponens from 4.2, 4.1)
 4.4. In(a,Y) -> In(a,Z). (Universal Instantiation from 3)
 4.5. In(a,Z). (Modus Ponens from 4.4, 4.3)


# 3: Uniqueness of the empty set
## Proof that
### If Y has no elements
### then Y = the empty set.

1. Let Y be any set. (Declaration)
2. Y has no elements. (Premise)
3. Y is a subset of the empty set. (Subset proof below)
 3.1. Let a in Y. (Assumption for subset proof)
 3.2. not In(a, Y). (Universal Instantiation from 2)
 3.3. a is in the empty set. (Explosion from 3.1, 3.2)
4. The empty set is a subset of Y. (Subset proof below)
 4.1. Let a in the empty set. (Assumption for subset proof)
 4.2. a is not in the empty set. (Set property)
 4.3. a is in Y. (Explosion from 4.1, 4.2)
5. Y = the empty set. (Set Equality from 3, 4)
