(*
J26 red-team cases for all four membership-specific set axiom citations.
One valid control and four invalid twins each differ only by replacing In
with R in one target axiom formula; all also exercise a -> f(a). The common
proof includes the valid SetProperty set-name replacement In(a,W) -> In(f(a),f(W)).

# 1: The set axiom rules permit closed-term replacement while preserving In
