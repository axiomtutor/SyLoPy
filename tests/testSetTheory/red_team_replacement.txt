# 1: Replacement needs a functionality hypothesis
## Invalid: the functionality hypothesis must have the form In(x, A) -> exists y — the implication needs an image for every member of A
### then exists C, forall y, (In(y, C) iff exists x, (In(x, A) and y = x)).

1. Let A be any set. (Declaration)
2. (forall x, In(x, A)) -> exists C, forall y, (In(y, C) iff exists x, (In(x, A) and y = x)). (Replacement)

# 2: Replacement's uniqueness clause must use the defining relation
## Invalid: the uniqueness clause must use B(x, z), obtained by substituting z for y in B(x, y) — a different antecedent is not the required functionality condition
### then exists C, forall y, (In(y, C) iff exists x, (In(x, A) and y = x)).

1. Let A be any set. (Declaration)
2. (forall x, (In(x, A) -> exists y, (y = x and forall z, (In(z, A) -> z = y)))) -> exists C, forall y, (In(y, C) iff exists x, (In(x, A) and y = x)). (Replacement)

# 3: Replacement must reuse the same bounding set
## Invalid: the same bounding set A must appear in both halves of Replacement — the image definition cannot range over a different source set
### then exists C, forall y, (In(y, C) iff exists x, (In(x, B) and y = x)).

1. Let A, B be any set. (Declaration)
2. (forall x, (In(x, A) -> exists y, (y = x and forall z, (z = x -> z = y)))) -> exists C, forall y, (In(y, C) iff exists x, (In(x, B) and y = x)). (Replacement)

# 4: Replacement's bounding set cannot depend on x
## Invalid: the bounding set A must not mention x — the source must be one fixed set
