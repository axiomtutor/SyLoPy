# 1: Membership characterization
## Proof that
### a set can be characterized by its membership condition
1. Let X be a set, P be a unary predicate such that a is in X iff P(a). (Declaration)

# 2: Empty-set characterization
## Proof that
### an unsatisfiable predicate characterizes the empty set
1. Let X be a set such that a is in X iff a =/= a. (Declaration)
