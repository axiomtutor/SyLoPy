# 1: A three-fold union is an ordinary nested term
## Proof that
### then In(x, Union(Union(A, B), C)).

1. Let A, B, C be any set, and x be any object. (Declaration)
2. In(x, Union(Union(A, B), C)). (Premise)
3. In(x, Union(Union(A, B), C)). (Reiteration from 2)

# 2: A member of the power set of a union is a subset of that union
## Proof that
### then x subseteq Union(A, B).

1. Let A, B be any set, and x be any object. (Declaration)
2. In(x, PowerSet(Union(A, B))). (Premise)
3. forall u, (In(u, PowerSet(Union(A, B))) iff u subseteq Union(A, B)). (Definition of power set)
4. x subseteq Union(A, B). (Set property from 3, 2)

# 3: A member of an intersection of a union belongs to that union
## Proof that
### then In(x, Union(A, B)).

1. Let A, B, C be any set, and x be any object. (Declaration)
2. In(x, Intersection(Union(A, B), C)). (Premise)
3. In(x, Intersection(Union(A, B), C)) iff (In(x, Union(A, B)) and In(x, C)). (Definition of intersection)
4. In(x, Union(A, B)) and In(x, C). (Set property from 3, 2)
5. In(x, Union(A, B)). (Conjunction Elimination from 4)

# 4: A nested union has the elements of the left and middle sets
## Proof that
### then In(x, A) or In(x, B).

1. Let A, B, C be any set, and x be any object. (Declaration)
2. In(x, Union(Union(A, B), C)). (Premise)
3. In(x, Union(Union(A, B), C)) iff (In(x, Union(A, B)) or In(x, C)). (Definition of union)
4. In(x, Union(A, B)) or In(x, C). (Set property from 3, 2)
5. In(x, Union(A, B)) iff (In(x, A) or In(x, B)). (Definition of union)
6. In(x, A) or In(x, B) or In(x, C). (Set property from 5, 4)

# 5: The union definition cannot be used for a different operation
## Invalid: definition mismatch — the intersection term is not the union term.
1. Let A, B be any set, and x be any object. (Declaration)
2. In(x, Intersection(A, B)) iff (In(x, A) or In(x, B)). (Definition of union)

# 6: The intersection definition cannot replace its conjunction with a disjunction
## Invalid: definition mismatch — membership in an intersection requires both memberships.
1. Let A, B be any set, and x be any object. (Declaration)
2. In(x, Intersection(A, B)) iff (In(x, A) or In(x, B)). (Definition of intersection)

# 7: The power-set definition cannot use membership in the underlying set
## Invalid: definition mismatch — members of a power set are subsets, not elements of the original set.
1. Let A be any set, and x be any object. (Declaration)
2. In(x, PowerSet(A)) iff In(x, A). (Definition of power set)

# 8: The union definition cannot omit one of its operands
## Invalid: definition mismatch — both A and B must occur in the disjunction.
